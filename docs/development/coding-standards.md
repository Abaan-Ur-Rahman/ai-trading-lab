# Coding Standards

## General Principles

- Write readable code before clever code.
- Favor simplicity over unnecessary complexity.
- Every public function must include a docstring.
- Prefer descriptive variable names.
- Avoid duplicated logic.
- Keep functions focused on a single responsibility.

## Formatting

Formatting will be handled automatically using Black.

## Linting

Static analysis will be performed using Ruff.

## Testing

Every production module should eventually have corresponding tests.

## Documentation

Important design decisions will be documented using Architecture Decision Records (ADRs).
